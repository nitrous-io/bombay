## Python Container Template

This setups a container template with:

- python 2.5
- python 2.6
- python 2.7
- python 3.2
- pypy

It also comes with some package:

- Google App Engine in $HOME folder
- setuptools
- pip
- virtualenv
- virtualenvwrapper
- System wide packages
  - Django==1.3.3
  - Fabric==1.4.3
  - Flask==0.9
